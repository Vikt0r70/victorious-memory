## Task 3: Persist primary_provider_id in update_agent_settings AND Update resolve_provider_chain

**Goal:** 
1. Update `update_agent_settings()` in service.py to persist the `primary_provider_id` field from the `AgentSettings` schema.
2. Update `resolve_provider_chain()` to **prepend** the `primary_provider_id` to the beginning of the fallback chain, so the gateway actually uses it at runtime.

<read_first>
- apps/api/app/domains/providers/service.py (current update_agent_settings and resolve_provider_chain functions)
- apps/api/app/domains/providers/schemas.py (AgentSettings schema)
</read_first>

<action>
1. In `apps/api/app/domains/providers/service.py`, in `update_agent_settings()`:
   - After setting `agent.fallback_provider_ids`, add:
     ```python
     agent.primary_provider_id = data.primary_provider_id
     ```
   - Ensure the assignment handles `None` correctly (the schema allows `str | None`).

2. In `resolve_provider_chain()` in the same file, **prepend** `primary_provider_id` to the chain:
   ```python
   async def resolve_provider_chain(
       db: AsyncSession, agent_role: str
   ) -> list[Provider]:
       """Resolve an agent's fallback chain to an ordered list of enabled providers."""
       agent = await get_agent_by_role(db, agent_role)
       if agent is None:
           return []

       # Build ordered list: primary first, then fallbacks
       provider_ids = []
       if agent.primary_provider_id:
           provider_ids.append(agent.primary_provider_id)
       if agent.fallback_provider_ids:
           # Avoid duplicates if primary is also in fallback list
           provider_ids.extend(
               [pid for pid in agent.fallback_provider_ids if pid != agent.primary_provider_id]
           )

       if not provider_ids:
           return []

       # Fetch providers in the order defined above.
       result = await db.execute(
           select(Provider).where(
               Provider.id.in_(provider_ids),
               Provider.is_enabled.is_(True),
           )
       )
       providers: dict[str, Provider] = {p.id: p for p in result.scalars().all()}

       # Preserve the order.
       return [providers[pid] for pid in provider_ids if pid in providers]
   ```
</action>
